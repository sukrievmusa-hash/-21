# Kezek — онлайн-запись и напоминания клиентам в Telegram

SaaS по подписке для малого бизнеса: салоны, барбершопы, ногтевые студии, репетиторы, автомойки и все, кто работает по записи.

**Что получает бизнес:** свою страницу онлайн-записи (ссылка + QR-код), журнал записей по мастерам, базу клиентов, уведомления о новых записях в Telegram. Клиенты получают напоминания за сутки и за 2 часа с кнопками «Приду» и «Отменить».

**Что получаете вы:** абонентскую плату 3 990 или 9 990 ₸ в месяц с каждого бизнеса (цены меняются в админке), оплата переводом Kaspi.

## Запуск

Всё настроено: база данных, бот-сервер, расписание напоминаний, сайт, аккаунт администратора.

- **Регистрация без писем.** Аккаунт создаётся сразу (edge-функция `account`), поэтому настройки почты в Supabase не нужны. Если владелец забыл пароль, он пишет в поддержку, а вы в админке → «Бизнесы» → бизнес → «Новый пароль владельцу» отправляете ему новый пароль в WhatsApp.
- **Администратор** — `sukrievmusa@gmail.com`. Пароль выдан в чате, смените его в `app.html` → «Настройки» → «Аккаунт». Дополнительного админа можно добавить кодом администратора на странице `admin.html`.
- **Telegram-бот** подключается в админке → «Настройки»: токен от @BotFather (`/newbot`). Затем «Подключить мой Telegram» — туда будут приходить новые регистрации и заявки на оплату.
- **Реквизиты Kaspi и контакт поддержки** — там же, в «Настройках».
- **Тарифы** — админка → «Тарифы»: название, цена, лимит сотрудников, ИИ и лимит ответов ИИ. Скрытый тариф (не виден на сайте) — для индивидуальных условий: создайте его и назначьте бизнесу в «Бизнесы».
- **ИИ-ассистент** — админка → «Настройки» → ключ DeepSeek (platform.deepseek.com) или Anthropic (console.anthropic.com). Владелец бизнеса на тарифе с ИИ заполняет базу знаний в кабинете → «ИИ-ассистент» (или пишет боту «Запомни: …»). Клиенты пишут боту — ассистент отвечает, ищет время и записывает; что не знает — пересылает владельцу, тот отвечает кнопкой «Ответить».
- **GitHub Pages** публикует сайт из ветки `gh-pages`. Чтобы выкладывалось из `main`, переключите: Settings → Pages → Branch: `main` → Save. Иначе после изменений выполняйте `git push origin main:gh-pages`.

**Проверка руками:** создайте тестовый бизнес в `app.html`, добавьте услугу, откройте свою ссылку записи с телефона, запишитесь, нажмите «Напомнить в Telegram», затем отмените запись кнопкой в боте.

## Как это устроено

```
GitHub Pages (статический сайт)          Supabase (проект kezek-booking)
 index.html  — лендинг                    Postgres + RLS — данные и правила доступа
 book.html   — запись клиента   ──RPC──▶  функции записи, слоты, отмена
 my.html     — моя запись                 pg_cron (каждую минуту) — напоминания
 app.html    — кабинет бизнеса  ──REST──▶ pg_net — отправка сообщений в Telegram
 admin.html  — ваша админка               Edge Function `tg` — webhook бота
```

- `supabase/migrations/001_schema.sql` — вся база: таблицы, права, функции, расписание, демо-бизнес.
- `supabase/functions/tg/index.ts` — сервер Telegram-бота (входящие кнопки и `/start`, подключение бота из админки).
- `supabase/functions/account/index.ts` — регистрация без письма и сброс пароля владельцу из админки.
- `supabase/migrations/002_signup_guard.sql` — ограничение частоты регистраций.
- `supabase/migrations/003_plans_ai.sql` — тарифы в таблице и ИИ-ассистент.
- `supabase/functions/tg/ai.ts` — ИИ-ассистент (DeepSeek или Claude): ответы, поиск времени, запись.
- `supabase/tests/self_test.sql` — самопроверка: `select * from private.self_test();` в SQL Editor прогоняет 30 сценариев (права, запись, наложения, напоминания, оплата, окончание подписки) и убирает за собой.
- `js/` — код страниц, без сборки. `vendor/` — supabase-js и генератор QR.

### Подписка и оплата
1. Бизнес выбирает тариф в кабинете → «Подписка», переводит деньги через Kaspi и нажимает «Я оплатил».
2. Вам в Telegram приходит заявка. Проверяете перевод в Kaspi → админка → «Оплаты» → «Подтвердить».
3. Срок продлевается сам, бизнесу приходит уведомление. Автосписаний нет.
4. За 3 дня и за 1 день до окончания бизнес получает напоминание. Когда подписка закончилась, онлайн-запись и напоминания останавливаются, данные сохраняются.

### Защита данных
- Каждый владелец видит только свой бизнес (Row Level Security в Postgres).
- Владелец не может сам продлить подписку или сменить тариф: эти поля закрыты на уровне прав базы.
- Клиент видит только свою запись по секретной ссылке. Наложение записей у одного мастера запрещено ограничением в базе.

## Обновление сайта
Правите файлы → `git push` (и `git push origin main:gh-pages`, если Pages всё ещё смотрит на ветку `gh-pages`). Сайт обновится за минуту.
Изменения базы: правите `001_schema.sql` (файл можно запускать повторно) и выполняете его в Supabase → SQL Editor.

## Ограничения бесплатных тарифов
- Supabase Free: база до 500 МБ, а неактивный проект могут приостановить через неделю без запросов. Когда появятся первые платящие клиенты, перейдите на Pro ($25/мес) — он окупается двумя-тремя подписками.
- GitHub Pages бесплатно работает только для публичного репозитория, поэтому код виден всем. Если это мешает, разместите сайт на Cloudflare Pages или Netlify из приватного репозитория. Секретов в коде нет: ключ `anon` публичный по замыслу Supabase.
- Свой домен (например `kezek.kz`): Settings → Pages → Custom domain, затем обновите адреса в Supabase (шаг 2) и в админке.
